## Setup (entorno virtual y dependencias)

1. Crear y activar entorno virtual, e instalar dependencias:

```bash
# crear el entorno e instalar dependencias
bash scripts/setup_venv.sh

# activar el entorno (Linux/macOS)
source .venv/bin/activate

# ejecutar la app (ejemplo)
streamlit run dech.py
```

2. `requirements.txt` contiene las dependencias necesarias (ej. `streamlit`).
